# AGENTS.md — homebrew-quillink

Homebrew tap for the Quillink CLI. `Formula/quillink.rb` is **generated by GoReleaser** on each `gcp-note-taking-cli` release (its `.goreleaser.yaml` `brews:` block), so fix anything here at that source first. A hand edit here is overwritten by the next release.

## Clean builds & CI (always enforced, even if not asked)

Green isn't enough: output must carry no warnings, deprecations or audit findings, even ones that don't break anything.

- After each CLI release, run `brew style Formula/quillink.rb` and `brew audit --strict --online dagistankaradeniz/quillink/quillink`, then fix what they report in the CLI repo's GoReleaser config.
- Fix the cause; never hide it. Don't suppress findings or silence output.
- If something can't be fixed (for example, GoReleaser generates it and offers no option to change it), say so in your report and give the reason.
