# AGENTS.md — homebrew-quillink

Homebrew tap for the Quillink CLI. `Casks/quillink.rb` is **generated by GoReleaser** on each `gcp-note-taking-cli` release (its `.goreleaser.yaml` `homebrew_casks:` block), so fix anything here at that source first. A hand edit here is overwritten by the next release.

`tap_migrations.json` moves users of the old `quillink` formula to the cask on their next `brew update`. Keep it.

## Clean builds & CI (always enforced, even if not asked)

Green isn't enough: output must carry no warnings, deprecations or audit findings, even ones that don't break anything.

- After each CLI release, run `brew style Casks/quillink.rb` and `brew audit --strict --online --cask dagistankaradeniz/quillink/quillink`, then fix what they report in the CLI repo's GoReleaser config.
- Fix the cause; never hide it. Don't suppress findings or silence output.
- If something can't be fixed (for example, GoReleaser generates it and offers no option to change it), say so in your report and give the reason. Known one: GoReleaser always writes a `# No zap stanza required` comment, which `brew style` flags as `Cask/ZapNotRequired`; it has no option to emit `zap :not_required`.
