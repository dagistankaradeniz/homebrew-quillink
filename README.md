# homebrew-tap

Homebrew tap for [Quillink CLI](https://github.com/dagistankaradeniz/gcp-note-taking-cli).

```sh
brew install dagistankaradeniz/tap/quillink
```

Formulas in `Formula/` are published automatically by [GoReleaser](https://goreleaser.com/) on every tagged release of `gcp-note-taking-cli` -- don't edit them by hand.
