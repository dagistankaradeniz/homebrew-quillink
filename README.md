# homebrew-quillink

Homebrew tap for [Quillink CLI](https://github.com/dagistankaradeniz/gcp-note-taking-cli).

```sh
brew install --cask dagistankaradeniz/quillink/quillink
```

The cask in `Casks/` is published automatically by [GoReleaser](https://goreleaser.com/) on every tagged release of `gcp-note-taking-cli` -- don't edit it by hand.

If you installed the old `quillink` formula, `brew update` moves you to the cask automatically.
